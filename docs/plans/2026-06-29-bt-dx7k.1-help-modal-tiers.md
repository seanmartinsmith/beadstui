# `?` overlay mini/full tiers + clean aesthetic — Implementation Plan (bt-dx7k.1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Invoke the **charm-tui-design** skill before any rendering code. Steps use checkbox (`- [ ]`).

**Goal:** Turn the bt-dx7k `?` overlay into a size-adaptive modal: a curated **mini card** when the terminal is short, the **full grouped sheet** otherwise — both rendered in one clean theme-tokened border (no rainbow per-group boxes), modeled on yazi's `yazihelp.yazi`.

**Architecture:** Reuse the bt-dx7k scroll/column/clamp plumbing (`helpOverlayColumns`, `helpOverlayAvailBody`, `helpScrollMax`, `handleHelpKeys` clamp). Replace the per-group rainbow `RenderTitledPanel` rendering with a single-box renderer (inline-divider section headers, single `│` column separator, dim-mono theme tokens). Add a height-driven mini/full selector and a curated mini projection of `GlobalKeys`. Rename the misleading `SearchMode` help desc. `?` stays global-only (locked `bt-y8uku`).

**Tech Stack:** Go 1.25+, Charm Bracelet v2 (`charm.land/...`), Lipgloss, Bubbles `key`. Tier-1 render harness (`BT_RENDER_DUMP=1`).

## Task 1: Single-box, theme-tokened renderer for the full sheet

**Goal:** Replace the four rainbow `RenderTitledPanel` group boxes with ONE rounded modal box whose interior shows the 4 task groups as columns, each group introduced by an inline divider header (`── SWITCH VIEWS ──`), columns separated by a single `│`, all in dim-mono theme tokens. No behavior change to scoping/scroll/columns.

**Files:** `pkg/ui/model_view.go`; tests in `pkg/ui/coverage_extra_test.go`.

**Interfaces (produce):**
- `helpRow{left, right string}` (lift to package scope or keep local + shared).
- `helpGlobalGroups() []helpGroup` where `helpGroup{title string; rows []helpRow}` — the 4 task groups (essentials-first: SWITCH VIEWS/DO THINGS/WORKSPACE/CHROME) projected from `m.keys.Global.FullHelp()` via the existing `bindingGroups` filter (enabled + has-help). Status legend handled separately (a `helpGroup` with literal rows, appended when there's room).
- `renderHelpGroupColumn(groups []helpGroup, colWidth int) []string` — stacks group blocks (inline-divider header + `key`/`desc` rows) vertically; returns lines.
- `helpOverlayBodyLines()` rebuilt: distribute groups across `helpOverlayColumns(m.width)` columns, render each column with `renderHelpGroupColumn`, JoinHorizontal with a dim ` │ ` separator, JoinVertical, split → lines. (Same flat-lines contract the scroll window already consumes.)
- `renderHelpOverlay()` wraps the windowed body in ONE `RenderTitledPanel` (rounded, `Title:"shortcuts"`, `CenterTitle:true`, `BorderColor`/`TitleColor` = subtle theme token), then `lipgloss.Place(m.width, m.height-1, Center, Top, boxed)`. Footer = a dim line under/inside the box (cross-ref + close + scroll%); if `RenderTitledPanel` can't weave a bottom-border footer, render it as the last interior line.

**Model the rendering on** `yazihelp.yazi`'s `render_col` (inline `─── label ───` divider + `rjust(key) + "  " + desc`) and bt's `shortcuts_sidebar.go` token usage (`keyStyle` bold bright, `descStyle` muted, `dimStyle` for headers/footer).

## Task 2: Mini card + height-driven tier selection

**Goal:** When the terminal is too short for the full sheet, render a curated mini card instead; grow the terminal → full sheet auto-appears.

**Files:** `pkg/ui/model_view.go`; tests in `coverage_extra_test.go`.

**Interfaces (produce):**
- `helpMiniRows() []helpRow` — curated projection, descs/keys sourced from each `GlobalKeys` binding's `Help()` (single-source), skipping disabled bindings:
  `Board`, `Graph`, `Insights`, `SearchBounce` (`/` "search"), `LabelPicker`, `Help`, `Back` (`q` "back / quit"). `ProjectsOrWisps` is appended **only when multi-project** (Task 3). Order them for a 2-column layout (board/graph, insights/search, labels/projects, help/quit).
- `renderHelpMini() string` — 2-column `key`/`desc` rows (reuse the Task-1 row styling) + a centered nudge line `↓ expand   ·   ; per-view`, wrapped in the same single box (`Title:"shortcuts"`, footer `esc ── q ── close`). Non-scrolling.
- selector in `renderHelpOverlay`: `if len(m.helpOverlayBodyLines()) > m.helpOverlayAvailBody() { return miniPlaced } else { full }` — i.e. mini when the full body can't fit the available height. (Mirror yazi `(area.h-2) < POPUP_H`.) Place the mini box `Center, Center` (it's small) or `Center, Top` — pick what reads best in the harness.
